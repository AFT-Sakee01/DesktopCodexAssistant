# Legacy Executables

This folder keeps historical local executable builds that were previously mixed into the project root.

Active release binaries are produced in the project root and copied to `Release/DesktopCodexAssistant-arm64.exe` and `Release/DesktopCodexAssistant-x64.exe`. Files here are retained only for traceability and are named by product, build timestamp, and a short SHA1 prefix.
