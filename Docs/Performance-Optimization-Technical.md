# 性能优化技术文件

## 设计依据

本次改动结合以下现有文档和代码注释实施：

- `Performance-And-Window-Runtime.md`
- `NetworkMonitor-Architecture.md`
- `PowerThermal-Architecture.md`
- `CodexRadar-Architecture.md`

保留的约束：

- UI 和 GDI 操作只在 UI 线程执行。
- 网络事件只设置失效标志，枚举和读取由调度线程完成。
- 功耗/温度采样保持单飞，挂起时停止，恢复时强制刷新。
- 设置窗口继续提供实时预览。
- Codex JSONL 追加必须使额度缓存失效。
- 所有新增原生和托管 GDI 资源必须显式释放。

## 日志存储

`Logger` 采用以下策略：

- INFO 先写入内存，达到 64 KB 或经过 5 分钟后批量追加。
- ERROR 先刷新 INFO 上下文，再立即写入主日志和错误日志。
- 单个活动日志达到 3 MB 时使用文件重命名轮转，不再读取并重写日志尾部。
- 日志目录上限为 10 MB，按时间删除最旧归档，活动日志受保护。
- 进程退出时调用 `Logger.Shutdown()` 刷新剩余缓冲。
- `--test-logger` 在系统临时目录验证轮转、总量限制和活动日志保护。

GFW 明细保留在内存中的最新结果。手动测试、首次结果、状态变化和异常立即写入；结果稳定时最多每 6 小时写一次完整明细。

## 窗口调度

主窗口的交互定时器统一驱动 Codex、功耗、网络和连接检测窗口：

- 各模块的数据采样定时器仍独立。
- 仅悬停命中、点击穿透和透明度动画共用一次 UI 消息泵唤醒。
- 动画进行时使用性能模式对应的动画间隔。
- 动画稳定后恢复低频轮询。
- Operation 窗口保留自身按状态启停的动画定时器。

全屏隐藏状态传播改为幂等操作。只有隐藏状态实际变化时才通知子窗口，避免每个主采样周期重复定位、重绘和触发功耗采样。

## 设置更新

- 设置界面的数值框和滑块事件使用 75 ms 防抖，合并同一用户操作产生的重复预览。
- 主窗口使用 `FileSystemWatcher` 监听 `settings.ini`，正常路径只检查内存失效标志。
- 监视器不可用时保留时间戳轮询回退。
- 设置窗口打开期间保留失效标志，不读取磁盘，避免与实时预览争用。

## 硬件采样

PDH 被拆分为两个查询：

1. 轻量查询：CPU、核心频率、磁盘和网络吞吐。
2. 昂贵查询：GPU/NPU 引擎和显存计数器。

GPU Engine 在当前机器展开为 357 个计数器。昂贵查询按模式更新：

| 模式 | GPU/NPU 间隔 |
| --- | ---: |
| Smooth | 1 秒 |
| Balanced | 2 秒 |
| BatterySaver | 5 秒 |

昂贵查询结果保存在内存中，轻量查询保持原采样频率。磁盘容量每 60 秒刷新；吞吐和忙碌率仍按主采样周期更新。网络名称、连接状态和 Wi-Fi 信息由网络变化事件使缓存失效。

## Codex 与功耗

- Codex 进程检测改为 `GetProcessesByName("codex")`，避免枚举系统全部进程。
- Codex 会话目录使用递归 `FileSystemWatcher` 失效额度缓存。
- 扫描前清除失效标志；扫描期间出现的新事件会保留到下一次刷新，避免丢失 JSONL 追加。
- 监视器不可用时恢复原轮询行为。
- 已由 `PowerThermalForm` 接管的 Codex 旧功耗/温度代码不参与编译。
- 功耗采样发现系统电源模式已知时不再重复调用后备检测路径。

## 分层窗口与字体

`NativeMethods.LayeredBitmapSurface` 为每个主要分层窗口长期持有：

- 一个兼容内存 DC。
- 一个当前内容 HBITMAP。

内容重绘时替换 HBITMAP；仅整体透明度变化时直接复用。窗口关闭时恢复原 GDI 对象并释放 HBITMAP/DC。

主面板、Codex、功耗、网络和连接检测窗口缓存布局相关字体。尺寸变化时清空缓存，窗口关闭时统一释放。动态拟合字体仍由原有代码按作用域释放。

## 生命周期和恢复

- 显示器恢复、会话解锁和显示变化继续进入延迟恢复流程。
- 功耗/温度模块在恢复时重新请求采样。
- 子窗口恢复、位置和可见性更新保持在 UI 线程。
- 文件监视器、定时器、字体缓存、位图、Graphics、HBITMAP 和 DC 均在关闭路径释放。

## 维护与验证

构建：

```powershell
.\Build-Arm64.ps1 -OutputPath .\DesktopCodexAssistant.exe
```

自检：

```powershell
.\DesktopCodexAssistant.exe --test-logger
.\DesktopCodexAssistant.exe --test
```

性能回归时至少检查：

- 6 个模块窗口均可见。
- 挂起/恢复后窗口仍可见且进程响应。
- GDI、USER、句柄和线程不随时间单调增长。
- `error.log` 没有新增异常。
- 稳定 GFW 检测不会每个周期写完整明细。
- BatterySaver 下单核等效 CPU 不应明显高于本次 0.60% 基线。
